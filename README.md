# Как выложить fcknggn, чтобы его мог установить любой

Всё в этой папке и есть готовое приложение. Его нужно один раз выложить на бесплатный хостинг, после чего у тебя будет ссылка вида `https://твоё-имя.github.io/fcknggn/`. Эту ссылку можно давать кому угодно.

## Выложить на GitHub Pages (бесплатно, навсегда)

1. Зарегистрируйся на github.com, это бесплатно. Имя пользователя попадёт в адрес приложения, так что выбирай его с умом.
2. Справа вверху нажми **+** → **New repository**.
   - Repository name: `fcknggn`
   - Выбери **Public**.
   - Нажми **Create repository**.
3. На странице нового репозитория нажми ссылку **uploading an existing file**.
4. Открой папку `fcknggn-app` в Finder, выдели **всё её содержимое** (Cmd+A) и перетащи в окно браузера. Перетаскивай именно содержимое, а не саму папку: файл `index.html` должен оказаться в корне.
5. Внизу нажми **Commit changes** и подожди, пока загрузится.
6. Открой **Settings** → слева **Pages**.
   - Source: **Deploy from a branch**
   - Branch: **main**, папка **/ (root)** → **Save**.
7. Через 1–2 минуты вверху этой страницы появится адрес приложения. Готово.

## Как поставить приложение на телефон

**iPhone:** открой ссылку в Safari → кнопка «Поделиться» → **На экран «Домой»**.

**Android:** открой ссылку в Chrome → меню ⋮ → **Установить приложение** (или «Добавить на главный экран»).

Появится иконка с курицей. Приложение открывается на весь экран и работает без интернета.

## Где хранятся записи

Только на телефоне у каждого человека. Никто, включая тебя, не видит чужие записи. Чтобы не потерять данные при смене телефона, в разделе «Статистика» есть кнопки **Сохранить копию** и **Загрузить из копии**.

## Как обновить приложение потом

1. Загрузи изменённые файлы в репозиторий так же, через **Add file → Upload files**, поверх старых.
2. В файле `sw.js` поменяй в первой строке `fcknggn-v1` на `fcknggn-v2` (потом `v3` и так далее), иначе у людей останется старая версия из кэша.

## Перенести свои записи из трекера в Claude

Записи из старого трекера в Claude сами сюда не переедут. Открой старый трекер → «Статистика» → **Скопировать сводку**, чтобы сохранить их текстом. Если захочешь перенести их в новое приложение целиком, попроси Claude добавить в старый трекер кнопку выгрузки в формате резервной копии.
